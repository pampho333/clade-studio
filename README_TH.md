# Clade Studio

**เครื่องมือแก้ไขทรีสายวิวัฒนาการแบบออฟไลน์ · เวอร์ชัน 1.8**

[한국어](README.md) · [English](README_EN.md)

## เริ่มใช้งาน

1. ดาวน์โหลด `Clade_Studio_Offline_v1.8_TH.html` จากหน้า Releases หรือดาวน์โหลด ZIP ของโครงการแล้วแตกไฟล์
2. เปิดไฟล์ HTML ใน Chrome หรือ Edge โดยไม่ต้องติดตั้งโปรแกรม ตั้งค่าเซิร์ฟเวอร์ หรือเชื่อมต่ออินเทอร์เน็ต
3. กด **เปิดทรี** หรือลากไฟล์ทรีมาวางในพื้นที่ทำงาน หากต้องการทดลอง ให้เลือก **เปิดทรีตัวอย่าง**

เมนู **ภาษา** ด้านบนใช้สลับระหว่างภาษาเกาหลี อังกฤษ และไทยได้ ไฟล์ทั้งสามรุ่นมีความสามารถเหมือนกัน ต่างกันเฉพาะภาษาเริ่มต้น เบราว์เซอร์จะจดจำภาษาที่เลือกแยกตามไฟล์เริ่มต้นเมื่อสามารถใช้พื้นที่จัดเก็บได้ การเปลี่ยนภาษาไม่แก้ไขข้อมูลทรี ชื่อวิทยาศาสตร์ ป้ายชื่อที่พิมพ์เอง ชื่อกลุ่ม หรือประวัติการเลิกทำ การตั้งค่าภาษาแยกจากไฟล์โครงการ

## ความสามารถหลัก

- นำเข้า Newick, NEXUS ที่มี TRANSLATE หรือหลายทรี และไฟล์ `.treefile` / `.contree` ของ IQ-TREE
- แสดงทรีแบบสี่เหลี่ยมหรือวงกลม ใช้ความยาวกิ่งหรือแสดงเฉพาะโครงสร้างการแตกกิ่ง พร้อมซูมและเลื่อนภาพ
- ยุบแต่ละกลุ่มโดยไม่ลบโหนดลูก ปรับขนาดรูปทรงที่ยุบได้แยกกัน ใช้ความกว้างเดิมก่อนยุบหรือกำหนดความกว้างเอง
- กำหนดรากใหม่ที่กึ่งกลางกิ่งก่อนถึงโหนดที่เลือก โดยคงระยะทางตามกิ่งและค่าสนับสนุนของกิ่ง รวมทั้งเรียงหรือกลับลำดับโหนดลูก
- ปรับความกว้างทรีทั้งหมดโดยรักษาสัดส่วนความยาวกิ่ง
- ทำเฉพาะชื่อวิทยาศาสตร์หรือข้อความที่เลือกเป็นตัวเอียง ย้ายค่าบูตสแตรปสีดำด้วยการลากหรือระบุระยะเลื่อน
- เพิ่มแถบสีกลุ่มและพื้นหลังแบบสีทึบหรือไล่สีได้อย่างอิสระ แถบสีและพื้นหลังแสดงในมุมมองสี่เหลี่ยม ส่วนสีกิ่งและป้ายชื่อใช้ในมุมมองวงกลมได้ด้วย
- เลือกแบบอักษรจาก 12 รายการ หรือระบุชื่อแบบอักษรที่ติดตั้งไว้ หากไม่มีจะใช้แบบอักษรสำรอง ไฟล์ SVG ไม่ฝังไฟล์แบบอักษร
- บันทึกโครงการ `.clade.json` เพื่อแก้ไขต่อ หรือส่งออกเป็น Newick, SVG และ PNG

## แป้นลัด

| แป้น | การทำงาน |
| --- | --- |
| `C` | ยุบ / ขยายกลุ่มที่เลือก |
| `R` | กลับลำดับโหนดลูก |
| `Shift+R` | กำหนดรากใหม่โดยอิงโหนดที่เลือก |
| `F` | พอดีหน้าจอ |
| `Ctrl+Z` | เลิกทำ |
| `Ctrl+Shift+Z` | ทำซ้ำ |
| `Ctrl+S` | บันทึกโครงการ |
| `/` | ค้นหาโหนด |

โปรดบันทึกไฟล์ `.clade.json` แยกไว้หากต้องการแก้ไขต่อ การบันทึกอัตโนมัติเก็บเฉพาะโครงการล่าสุดในเบราว์เซอร์นี้ และอาจได้รับผลจากการตั้งค่าเบราว์เซอร์หรือตำแหน่งไฟล์ HTML ส่วน Newick เก็บโครงสร้างทรีแต่ไม่เก็บรูปแบบการแสดงผล กลุ่มที่ยุบจะส่งออกพร้อมโหนดลูกทั้งหมด ภาพ SVG และ PNG ไม่รวมเส้นเลือกหรือจุดปรับขนาด

รองรับไฟล์สูงสุด 8 MB ทรีสูงสุด 10,000 โหนด และความลึก 500 ระดับ ทรีขนาดใหญ่อาจทำงานช้าลง ความยาวกิ่งที่ไม่มีค่าหรือติดลบจะแสดงเป็นศูนย์ โดยยังเก็บค่าติดลบเดิมไว้ โปรแกรมนี้แก้ไขทรีที่มีอยู่แล้ว ไม่วิเคราะห์สร้างทรีหรือคำนวณค่าบูตสแตรปใหม่ ข้อมูลตัวอย่างเป็นข้อมูลสมมติ ข้อมูลทรีประมวลผลในเบราว์เซอร์โดยไม่มีบริการอัปโหลดทรี

## สำหรับผู้พัฒนา

ต้องใช้ Node.js 20 ขึ้นไปและ Python 3.9 ขึ้นไป โดยไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

```bash
npm run check
npm test
python3 build-offline.py
node --check .build/bundle-check.js
```

บน Windows หากไม่มีคำสั่ง `python3` ให้ใช้ `py -3 build-offline.py` แก้ไขซอร์สใน `src/` แล้วสร้างไฟล์ใหม่ สคริปต์จะสร้าง HTML ทั้งสามภาษาและ `index.html` คำแปลอยู่ใน `src/i18n.js` ชุดทดสอบตรวจสอบการแปลและการคงข้อมูลเดิม โดยข้ามการทดสอบเสริมสองรายการที่ต้องใช้ข้อมูลวิจัยแยกต่างหาก การทดสอบอัตโนมัติไม่แทนการตรวจหน้าจอในเบราว์เซอร์

Clade Studio เป็นเครื่องมืออิสระที่ได้รับแรงบันดาลใจจาก [iTOL](https://itol.embl.de/) ไม่ใช่ผลิตภัณฑ์ทางการของ iTOL ส่วนหัวใช้โลโก้ห้องปฏิบัติการอนุกรมวิธานแมลง มหาวิทยาลัยแห่งชาติคังวอนที่ผู้ใช้จัดเตรียมให้ ดูประวัติเวอร์ชันใน [CHANGELOG.md](CHANGELOG.md)
