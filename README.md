# Clade Studio

**브라우저에서 실행하는 오프라인 계통수 편집기 · 수정 버전 1.7**

Newick·NEXUS·IQ-TREE 트리를 불러와 분기군을 접고, 접힌 도형의 크기·라벨·부트스트랩 위치·분류군 색상을 조절합니다. 설치나 서버 없이 HTML 파일 하나로 실행합니다.

An offline, browser-based phylogenetic tree editor with independently resizable collapsed clades, rerooting, partial label italics, and taxon color bars and backgrounds.

## 실행하기

1. 이 저장소를 ZIP으로 내려받고 압축을 풉니다.
2. **[Clade_Studio_Offline_v1.7.html](Clade_Studio_Offline_v1.7.html)** 또는 **[index.html](index.html)**을 Chrome이나 Edge에서 엽니다. 두 파일의 내용은 같습니다.
3. **트리 열기**를 누르거나 트리 파일을 화면에 끌어 놓습니다.

일반 사용에는 Node.js, Python, 인터넷 연결이 필요하지 않습니다. 바로 확인하려면 앱의 예제 트리 또는 [examples/demo.nwk](examples/demo.nwk)를 사용하십시오. 예제는 기능 설명을 위한 가상 데이터입니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 트리 불러오기 | Newick, NEXUS의 TRANSLATE·다중 트리, IQ-TREE `.treefile`·`.contree` |
| 트리 표시 | 직각·원형, 원본 가지 길이 또는 위상 표시, 확대·이동 |
| 분기군 접기 | 하위 데이터를 보존하면서 접기·펼치기 |
| 접힌 도형 | 삼각형·사각형·타원, 노드마다 폭·높이 조절, 원래 분기군 폭에 자동 맞춤 |
| 재루팅 | 선택 노드로 들어오는 가지의 중간에 루트를 두고 선택 분기군과 나머지 트리로 분리 |
| 분기군 정렬 | 하위 노드 순서 뒤집기, 말단 수가 적은 분기군부터 정렬 |
| 라벨 편집 | 화면 표시 이름, 학명 부분만 이탤릭, 직접 선택한 문자열만 이탤릭 |
| 부트스트랩 | 검은색 표시, 드래그 이동, X·Y 오프셋·정렬 조절 |
| 분류군 색 띠 | 선택 분기군 또는 라벨 검색으로 대상 지정, 오른쪽 색 띠·분류군 이름 |
| 분류군 배경 | 단색·그라데이션, 색 띠와 독립적인 배경색·진하기·폭·이름 정렬 |
| 글꼴 | 12개 글꼴 목록, 설치된 글꼴 이름 직접 입력, 미리보기 |
| 저장·내보내기 | 편집 프로젝트 `.clade.json`, Newick, SVG, PNG, 실행 취소·다시 실행 |

## 자주 쓰는 작업

### 분기군 접기와 크기 조절

노드를 선택하고 **접기**를 누릅니다. 오른쪽 설정에서 접힌 도형의 가로 폭·높이·모양을 바꾸거나 도형의 조절점을 끌어 크기를 변경할 수 있습니다.

**접기 전 분기군 폭에 맞추기**를 켜면 해당 노드부터 가장 먼 하위 말단까지의 원래 가로 범위에 맞춥니다. 직접 폭을 조절하면 수동 크기로 전환됩니다. 접기는 하위 노드를 삭제하지 않습니다.

### 전체 트리 폭 줄이기

**표시 설정 → 가지 길이 → 원본 길이 사용 · Phylogram**을 유지한 상태에서 **트리 가로 폭**을 줄입니다. 가지 길이의 상대 비율과 원본 수치를 유지하면서 그림의 가로 크기를 조절합니다. 글자 크기는 별도로 조절합니다.

### 루트 변경

기준이 될 말단 또는 내부 분기군을 선택하고 **루트 지정**을 누릅니다. 선택 분기군이 첫 번째 루트 자식으로 배치되며, 나머지 분기군의 표시 순서가 정렬됩니다. 실제 루트 위치는 선택 노드의 바로 앞 가지 중간입니다. 직각 보기에서는 루트 왼쪽에 짧은 꼬리선을 표시합니다.

가지 길이와 지지도는 재추정하지 않습니다. 재루팅으로 하위 구성이 달라진 접힌 분기군은 펼쳐질 수 있습니다. 결과를 되돌리려면 `Ctrl+Z`를 누릅니다.

### 학명만 이탤릭으로 표시

노드를 선택하고 라벨의 기울임 설정을 변경합니다. 학명 자동 인식 외에, 라벨 입력란에서 원하는 부분을 선택해 그 부분만 이탤릭으로 지정할 수 있습니다. 자동 인식 결과는 표본 코드나 특수한 이름에서 직접 확인하십시오.

### 색 띠와 배경

- **색 띠:** 노드를 선택한 뒤 **분류군 색** 또는 **선택 분류군에 색 띠 추가**를 누릅니다.
- **배경:** 노드를 선택한 뒤 **배경색 → 그림처럼 그라데이션**을 누릅니다.
- 색 띠와 배경은 함께 사용할 수 있고, 배경에 별도의 색을 지정할 수 있습니다.
- 배경의 범위는 오른쪽 분류군 이름 영역, 말단 라벨부터, 트리 전체 너비 중에서 선택합니다.
- 한 분류군에 속한 말단이 떨어져 있으면 연속된 구간마다 따로 표시합니다. 서로 겹치는 분류군의 오른쪽 표시는 별도 열에 배치합니다.

색 띠·배경은 **직각 보기**에서 표시됩니다. 가지·말단 라벨의 색은 원형 보기에도 적용됩니다.

### 글꼴 변경

상단 **글꼴** 버튼 또는 **표시 설정 → 트리 글꼴**을 사용합니다. Arial, Times New Roman, Helvetica, Georgia, Verdana, Calibri, Cambria, Palatino Linotype, Courier New, Consolas, 맑은 고딕, 바탕을 선택할 수 있습니다.

목록에 없는 글꼴은 **다른 설치 글꼴 직접 입력**을 선택한 뒤 이름을 입력하고 Enter를 누릅니다. 설치되지 않은 글꼴은 대체 글꼴로 표시됩니다. SVG에는 글꼴 파일을 포함하지 않으므로, 다른 컴퓨터에서도 같은 글꼴을 사용하려면 해당 글꼴이 설치되어 있어야 합니다.

## 저장과 데이터 보존

| 형식 | 보존되는 내용 |
| --- | --- |
| `.clade.json` | 트리, 접기 상태, 도형 크기, 라벨 서식, 색 띠·배경, 글꼴 등 편집 설정 |
| Newick | 현재 루팅·노드 순서와 원본 이름·가지 길이·지원되는 지지도 정보. 화면용 색상·도형 서식은 제외 |
| SVG | 벡터 그림. 커서·선택 테두리·조절점은 제외 |
| PNG | 래스터 그림. 큰 트리는 출력 크기 제한이 적용될 수 있음 |

자동 저장은 해당 브라우저의 마지막 작업 한 개에만 적용됩니다. HTML 파일 위치나 브라우저 설정에 따라 복원이 제한될 수 있으므로, 편집을 이어가려면 **프로젝트 파일을 별도로 저장**하십시오. 새 버전에서도 기존 `.clade.json`을 불러올 수 있습니다.

트리 데이터는 브라우저 안에서 처리하며, 앱에는 트리 업로드 서버나 외부 분석 API가 없습니다. 도움말의 외부 링크를 클릭하면 해당 웹사이트로 이동합니다.

## 개발 및 빌드

필요 환경: **Node.js 20 이상**, **Python 3.9 이상**. 외부 패키지 설치 없이 빌드와 테스트를 실행할 수 있습니다.

```bash
npm run check
npm test
python3 build-offline.py
node --check .build/bundle-check.js
```

Windows에서 `python3` 명령이 없으면 `py -3 build-offline.py`를 사용하십시오.

빌드하면 저장소 루트에 `index.html`과 `Clade_Studio_Offline_v{버전}.html`이 생성됩니다. 버전은 `src/index.html`의 `clade-studio-version`에서 읽습니다. 기능을 수정할 때는 버전과 `CHANGELOG.md`를 함께 갱신한 뒤 다시 빌드합니다. 생성된 HTML 대신 `src/`의 원본 코드를 수정하십시오.

| 경로 | 용도 |
| --- | --- |
| `index.html` | 최신 단일 HTML 실행 파일 |
| `Clade_Studio_Offline_v1.7.html` | 버전이 표시된 실행 파일 |
| `src/index.html` | UI 구성과 버전 메타데이터 |
| `src/style.css` | UI 스타일과 오프라인 커서 |
| `src/core.js` | 파서, 트리 배치·재루팅, 프로젝트 검증 |
| `src/app.js` | 화면 조작, SVG 렌더링, 저장·내보내기 |
| `build-offline.py` | CSS·JavaScript를 HTML 하나로 통합 |
| `tests/` | 파서·서식·재루팅·색상·커서·글꼴 회귀 검사 |
| `examples/demo.nwk` | 가상 예제 트리 |
| `CHANGELOG.md` | 수정 버전별 변경 내용 |

테스트는 Node.js에서 실행하며, 실제 브라우저 화면 검사를 대신하지 않습니다. 별도의 로컬 연구 트리를 요구하는 회귀 검사 2개는 기본적으로 건너뜁니다. 해당 원본 파일과 사용자 편집 프로젝트는 저장소에 포함하지 않습니다.

## 지원 범위

- 파일 입력은 최대 8 MB, 트리는 최대 10,000개 노드·깊이 500까지 처리합니다. 큰 트리의 반응 속도는 컴퓨터 환경에 따라 달라집니다.
- 누락된 가지 길이는 화면에서 0으로 표시합니다. 음수 길이도 화면에서는 0으로 표시하되 원본 값은 보존합니다.
- 이 앱은 기존 트리를 편집하고 표시합니다. 계통수 추론이나 부트스트랩 재계산을 수행하지 않습니다.
